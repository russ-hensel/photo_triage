This is an application to quickly review photos and classify them as
* Ok
* Duplicates
* Deletes

  I does this by displaying 4 photos at a time each with its own button for classification.  After a button is pressed the photo is
  moved to a sub-directory to indicate its classification.  To better judge photos that are incorrectly oriented buttons also allow a
  photo to be rotated.

  This process can be very quick, in simple cases down to a few seconds for each photo.

  Since modern cameras encourage us to take multiple photos, getting rid of the less desirable ones quickly can be a blessing.
